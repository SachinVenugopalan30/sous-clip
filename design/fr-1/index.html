Sous Clip v2 / A redesign in four worlds

Four ways to
keep a recipe.

The product is the same in every direction: a private library, a visible extraction line, a recipe you can cook from, and a phone that takes the link. Only the room changes.

Each direction is a complete set of live screens, not a mood board: library, extraction, recipe, phone and settings. One uses the palette already in the app; the other three are new.

5 screens each Real content Live HTML, not images

What actually changes.

Every direction covers the same product truth and the same five screens. The differences are in the room, not the workflow: how the library is browsed, how extraction shows its work, and how a recipe reads at the stove.
