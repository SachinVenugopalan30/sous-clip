# Sous Clip frontend

React 19, TypeScript 7, Vite 8 and Tailwind 4, with Bun. Design system: [DESIGN.md](../DESIGN.md).

- `bun run dev` starts the dev server (proxies `/api` to `localhost:8000`)
- `bun test src` runs tests
- `bun run build` type-checks and builds
- `bun run lint` lints with oxlint
